# v0.3.4 · Mac 审查反馈整改

日期：2026-10-21。基线是已交付 v0.3.3；本版保留场景教学、四种练习模式、原词库和听力素材，集中处理可重复验证、模型凭证与回退、请求边界和维护成本。

## 已修复

- 听力测试先规范系统临时目录的真实路径，支持临时目录祖先为符号链接的环境；生产素材路径仍拒绝符号链接。构建器返回稳定错误码，缺模型、路径问题、素材缺失和摘要不符分别断言。
- 统一测试入口优先使用显式 `PYTHON`、项目 `.venv`，再使用 `python3`。先检查 pytest、Node、ffmpeg/ffprobe，并记录版本；缺依赖给安装提示。新增 Linux/macOS、Python 3.11/3.12 的 CI 配置。
- 学生模型 Key 使用独立主密钥认证加密，密文绑定学生 ID；数据库、辅助文件和主密钥为0600。已迁移库缺失／损坏主密钥时停止；有已保存密文时，不匹配主密钥与损坏密文也明确失败，不自动覆盖。
- 增加 `schema_migrations`，串行迁移旧库并清理仍可能含旧明文的 SQLite 空闲页与 WAL。清理中断可重试；迁移锁使用独立 sidecar，权限调整不会关闭 SQLite 正在使用的 inode 描述符。
- 部署脚本与手工 CLI 使用同一份环境文件中的数据库、词库和主密钥路径，避免创建学生时写入另一数据库。
- 自带模型失败后的平台回退改为严格布尔值 `allow_platform_fallback`，新旧学生默认关闭。设置页解释数据去向与成本，显示最近调用状态；错误不再静默换模型。明确开启后才允许回退，并返回实际 provider、回退标记和安全原因。
- 保留每日20次生成尝试上限；新增已确认成功次数、剩余次数及 UI。成功仅在场景五字段通过验证后记入，跨午夜按请求原日期记录。生成期间修改草稿也会刷新已使用次数，旧回复不覆盖新草稿。
- `PublicClient` 在一个学生脑端生命周期内复用连接池，提供 `aclose()`，脑端退出时清理。不同事件循环不混用，业务 POST 不增加自动重试。
- 保留既有 PCM WAV 格式、采样率、声道和30秒校验；补齐畸形 RIFF 错误、Content-Type、上传时限、每进程4个 ASR 处理槽和本地识别等待上限。超时或取消后，仍运行的本地工作占用原槽直到真正结束。
- 公共接口增加安全错误码、关联请求 ID 和结构化耗时日志。参数校验不回显 `input/ctx` 中的 Key／正文；未知运行时异常保持500并给安全信息。场景超时由模型服务统一管理，同时更新最近调用状态。
- settings/today 共用轮询工具；前一次结束后再调度，成功10秒、连续失败20/40/60秒，隐藏／卸载停止，重新显示或切换课堂重置。
- 原 `miniprogram/` 继续作为唯一源码，独立包从构建器生成；回归核对完整文件集合和内容。

## 必须了解的升级变化

本版新增 `cryptography==50.0.2`，需更新运行依赖。首次打开旧数据库会迁移密钥格式；升级前备份，升级后分别保管数据库和原主密钥。**已迁移数据库不能交给 v0.3.3 直接运行。** 完整步骤见 [UPGRADE.md](UPGRADE.md)。

旧学生的回退开关默认关闭；如确实希望自己的供应商失败后使用平台，需在新版设置页明确开启并测试保存。成功计数从本版启用后开始，旧版尝试不能解释成全部失败。

本轮未增加完整 router/repository 框架、依赖 extras 或主密钥在线轮换。已按实际职责抽出模型编排、迁移、凭证存储和诊断模块，保留 requirements 入口与精确版本固定。没有上线、调用用户真实供应商或操作生产数据库。

完整审查逐项回应见 [REVIEW_V034.md](REVIEW_V034.md)，实际测试结果见 [TEST_REPORT.md](TEST_REPORT.md)。
