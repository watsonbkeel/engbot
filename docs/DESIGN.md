# 设计说明 · v0.3.4

## 1. 责任边界

公共层管理原词库、配置、按学生隔离的进度及供应商凭证；每学生脑端运行自己的课程状态机；Pi 主动录音、发送当前题的答案并播放回复；家长小程序配置练习和查看记录。

模型提供语义判断和对话，不拥有数据库工具或配置修改能力。代码校验结构、掌握条件、题位和幂等性。测试模型只在 tests/ 中，正式环境失败会明确报错；学生模型仅在家长明确开启allow_platform_fallback后才可改用真实平台供应商。ASR的备选识别按老师服务器配置运行。

## 2. 四种模式与帮助

| 模式 | 主要阶段 | 结束条件 |
|---|---|---|
| full | listen → recall → dialog | 词汇完成后结束短对话，或用户停止／时间上限 |
| en2zh | listen | 本批听辨完成，或用户停止／时间上限 |
| zh2en | recall，必要时 repeat | 本批主动说词完成，或用户停止／时间上限 |
| scene | 开场练习 → 角色对话 → 点评 | 自然完成，或到达 6/8/10 轮上限，或用户停止 |

场景开场按大小写、标点和空格归一匹配，两次未匹配就慢速示范并进入角色，避免卡在门口。没有配置场景的兼容请求使用通用对话，通用轮数为 4/6/8。

v0.3.3 在每次对话请求中提供 `dialogue_budget={total_turns,completed_turns,remaining_turns}`；completed 包括正在处理的当前学生回答，不包括开场模仿、解释、求助及重复播放。模型因此能提前安排核心任务，而不是最后一轮才知道要结束。

配置场景的模型回复可带严格布尔值 `scene_complete`。只有已有至少两轮学生交流、本轮 `relevant=true` 且模型明确返回 true，才允许在上限前结束；未返回字段按 false 兼容旧模型，畸形值拒绝且保持原题。提示词要求实际交流已经完成核心目标，且学生自然接受结果或告别。该信号只改变会话结束时机，不给任何单词加分，不证明真实学习能力或现实任务完成；逐词证据仍单独校验。最后角色回复、点评和结束语仍按原顺序播报。

场景生成保留学生指定的双方角色、主目标和谁提问，核心任务要求六轮简短交流可完成。学生当店员或采访者时，机器人可仅回答，不强行追加问题。到达上限但目标尚未完成时，提示词要求诚实收尾，不能虚构付款、找到物品或成功。

explain 解释当前问题，保留题位。howtosay 在中文帮助开启时收集中文意图、提供英文示范、检查跟读，再返回保存的原题；不会把中文意图当英语答案。中文帮助关闭时给固定英文支持，正常线索和模型回复也检查是否违反英文要求。

“受过帮助”与“实际被示范的词”分开记录：前者阻止当题证据升级为独立掌握，后者用于识别示范后的输出；只有符合当前任务或有正确证据的重复才增加模仿次数。上下文和断点恢复都保留这些标志，不能靠暂停、退出或重试把刚听到的答案变成独立回答。

v0.3.2 给当前判断传 answer_support，并在对应学生历史句保留同一 support；它们只包含求助布尔值及原 word_id。lesson_observations 保留本批最多 10 词最新的阶段、正确、独立和模仿事实，传给原有对话／点评调用，不增加请求或数据库评分。旧快照只显式补新字段默认值，不将当前失败回合的临时状态合入旧快照。

模板优先提供“文具店”和“午餐点餐”，同时保留原兴趣场景。对话提示接受符合语境的短回答，回应学生的相关问题；按需提供选择与一次有用改述，不要求每个回答都凑成完整句。困难词只在合适情境中再练。

## 3. 掌握证据

听辨正确且未被提示时可以达到 1；独立说出且语义正确时可以达到 2。full 保留听辨前置；zh2en 和纯 scene 为独立练习模式，明确的独立正确证据可直接到 2。数据库保留历史最高档。

对话一次模型调用返回所有提到的目标词的 `{word_id,correct,independent}`，不再从整句 relevant 推断所有词正确，也不为每词多请求一次模型。代码另核对目标词确实出现、是否是选项／示范回声、是否受过帮助。证据缺失或畸形时不升级，返回 evidence_incomplete 供观察，仍可继续正常角色回复。

失败的跟读不写“成功模仿”；没听清单独计数，不降低档位。最后一次角色回复先保留，再接基于实际对话的赞许和最多三条建议，最后收尾。点评服务失败也允许孩子退出，不编造点评。

明确单词跟读只比较规范化整答与刚示范的原词／原短语，容忍大小写、标点和空格；不调用通用词形推导。正常回忆／对话仍接受有语义证据的合理词形。释义正确但没有说出目标词时，反馈分别说明表达成功和取词仍需练习。结果页使用历史最高达成与累计记录文案；旧模仿计数不追认全部为成功，也不伪装为当日熟练度。

## 4. 跨服务可靠性

单学生脑端使用串行锁。每个答案带 request_id、session_id、question_id；旧题位在 ASR／写库前拒绝。同编号重试优先返回首次完成结果，因此响应丢失后不会将旧答案送给下一题。

进度库本身按幂等键去重。脑端短期日志在调用前保存写入意图，保存已完成读／判题结果，失败重试时按顺序重放；不对已经提交的进度重新判一个不同结论。接下来的提示生成成功、响应和新状态持久化后，才提交续学断点清理。

新 pending 附带 executor_version，FORMAT_VERSION 仍为 1。旧或不同执行版本的未确认回合不进入新引擎重演：原请求先按原载荷与幂等键结算未确认 record，逐项持久化，再原子缓存明确的升级结束回复。失败保留待确认意图；完成缓存落盘后才清旧续学断点。孩子明确 stop 可不等待故障写入服务而直接退出，原编号与 stop 编号分别缓存同一结束状态。没有 pending 的旧状态只补字段默认值；旧完成回复照常回放。

新坏 WAV 在创建 pending 前返回 422，Pi 重新录制当前题；已有完成回放、旧题拒绝与跨版本收尾优先于录音格式校验，避免旧版坏录音 pending 再次卡住。

Pi 在结果不确定时冻结后续答案，保留唯一待确认请求，重复发送原编号与原内容。明确停止可退出这个恢复等待；停止控制不会被旧题位锁死。脑端日志最多缓存 128 个回复并设 6 小时有效期；Pi 待确认录音同样短期保存。词汇续学断点另保留 7 天。这里实现的是有限恢复，不是永久录音或对话档案。

## 5. 接口、状态与资源

配置、场景、thinking和平台回退开关都严格校验。数据库有版本化迁移，旧学生与学习记录保留；模型Key由独立主密钥认证加密并绑定学生。迁移清理可重试，已迁移库缺失／损坏主密钥时停止，有模型密文时可验证并拒绝不匹配主密钥。家长连接先验证候选、再保存，草稿按连接身份隔离。

场景编辑器有“仅保存场景”和“保存并去安排练习”两个动作。后者只先保存场景，再把已确认场景的选择交接给同课堂的今日页；今日页保留其他未保存选项、选中场景模式，并明确要求最后保存安排。短期内存交接绑定课堂身份与场景内容；隐藏页面、保存失败、课堂切换或场景已替换时不能激活旧选择。设置 API 的一次页面跳转保留本课堂场景草稿，不保存模型密钥到交接状态。

脑端独立报活，Pi 即使空闲也 tick。前端按服务端时间判断新鲜度：脑端 60 秒、Pi 30 秒、SSH 60 秒；未来／过期时间显示未知。SSH 是可选的服务端探测，多学生显式映射设备，不把某一台的在线状态用于其他学生。

家长自带模型地址只允许公网 HTTPS；DNS 在线程池内有界执行，超时覆盖 DNS 和请求。实际连接固定到已验证 IP，保留原 Host、SNI 和证书主机名验证，不使用环境代理；连接失败可在同一截止时间内尝试其他已验证 IP。老师配置的平台模型保留原网络行为。供应商畸形响应归一为可处理错误，Vosk 冷启动单次加载。语速贯穿引擎、Pi 和供应商。

听力是单独的预生成文件产品：原稿、音频、时长、摘要写入清单；API 只读、鉴权下载、校验目录边界；退出页面停止播放器并使晚到回调失效。它不访问 Pi，不实时生成，不写口语掌握记录。

v0.3.4将模型选择编排抽到ModelService，自带模型与可选回退共享截止时间。公共请求带request_id，参数校验不回显输入；诊断只记类别、散列标识与耗时。PublicClient复用同学生、同事件循环的HTTP池，退出关闭，不自动重试业务POST。

ASR公共路由提前校验格式及媒体类型，上传和处理均有时限，每进程共享4个工作槽。取消不释放实际仍运行的本地工作；限制积压，但不声称能终止卡住的原生线程。前端轮询在上次请求结束后才调度，失败20/40/60秒退避，隐藏暂停，课堂切换隔离。

每天20次场景生成仍按尝试预留，另记完整五字段成功；没有失败退款。次数读取与草稿生成使用不同失效边界：同页同课堂编辑可以刷新用量，迟到生成不能覆盖草稿，换课堂或隐藏后均不写界面。

## 6. 仍由真实环境决定的效果

结构和状态正确不等同于真实模型始终判断准确。儿童语音识别率、模型纠错是否合适、网络延迟、实际朗读听感、微信与耳麦体验，要按 INSTALL 的真机矩阵验收。本包测试报告清楚区分这些边界。
