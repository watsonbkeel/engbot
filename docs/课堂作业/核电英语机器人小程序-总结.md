# 核电英语机器人小程序 · 总结

> 依据：《核电英语机器人小程序-内容文档提示词.md》  
> 用途：一页看懂这个小程序长什么样、有哪些功能、每个功能的关键点。
>
> ⚠️ **核心定位（开发必读）**：小程序只是**壳 / 载体**，负责展示卡片和提供聊天界面。  
> 聊天时和孩子对话的主体**始终是「机器人」**——所有回答都由机器人给出。  
> **不存在**"小程序自动答题 / 小程序回答问题"这类交互；涉及问答的内容全部是**预置给机器人的语料**。

---

## 一、小程序样貌

一款**微信小程序**（只是壳），面向一至十二年级。整体是"看卡片 + 和机器人聊天学英语"的样子：

1. **科普卡片页**：10 个核电主题以卡片形式排列在页面上，每张卡片点开就是一篇双语科普短文。卡片只是**展示内容**，不答题、不互动测验。
2. **对话机器人**：聊天界面里是**机器人**在和孩子对话——孩子用英语发问，**机器人**用中英双语回复。页面背后是小程序壳，但说话的永远是机器人。
3. **单词卡**：所有学过的重点词汇汇总成按字母排序的单词卡。

**视觉与文字风格**：

- 英文：简单短句（CEFR A2 难度，每句不超过 15 个词）
- 中文：口语化翻译，配适量 emoji（每个标题最多 1 个）
- 整体基调：正面、友好、童趣，不吓人

## ssh -p 49222 root@二、功能清单（含关键点）

### 功能 1：科普卡片（10 大核电主题）

| 项目      | 内容                                                                                                  |
| ------- | --------------------------------------------------------------------------------------------------- |
| 是什么     | 以卡片形式展示的核电双语科普内容                                                                                    |
| **关键词** | **10 大主题**：①什么是核电 ②核电站怎么发电 ③反应堆初识 ④核电安全吗 ⑤生活中的辐射 ⑥核废料去哪儿了 ⑦核电与绿色能源 ⑧中国核电（大亚湾、华龙一号）⑨核电站里的工作 ⑩核电趣味冷知识 |

**每个主题的"五件套"固定结构（缺一不可）**：

1. **Title**：英文标题 + 中文标题
2. **科普短文**：英文 80~120 词 + 中文对照翻译
3. **重点词汇**：5 个，含 单词 / 音标 / 词性 / 中文 / 英文例句
4. **机器人问答语料**：3 组 Q\&A——这是**预置给机器人的语料**：孩子问到这些问题时由**机器人**作答，不是小程序弹出答题页；问法要像小学生真的会问的
5. **趣味事实**：1 条

### 功能 2：英语对话机器人（核心功能，交互主体）

| 项目      | 内容                                                                                                             |
| ------- | -------------------------------------------------------------------------------------------------------------- |
| 是什么     | **对话的双方是"孩子 ↔ 机器人"**：孩子用英语发问，机器人双语回复。小程序只提供聊天界面，不参与回答                                                          |
| **关键词** | **四类语料**（全部是喂给机器人的）：①打招呼 / 自我介绍（3 组）②话题引导——机器人主动推荐 10 个主题（5 组）③**听不懂 / 兜底回复**（5 组，要鼓励孩子换简单说法，不能让孩子受挫）④告别语（3 组） |

**语料格式（开发按此配置）**：`[场景标签] 用户说：… / 机器人答：英文 + 中文对照`

### 功能 3：词汇表 / 单词卡

| 项目      | 内容                         |
| ------- | -------------------------- |
| 是什么     | 汇总所有主题的重点词汇，做成单词卡          |
| **关键词** | **按字母排序**、含**音标**与**中文释义** |

## 三、贯穿所有功能的硬性要求

| 要求   | 关键词                                                                                            |
| ---- | ---------------------------------------------------------------------------------------------- |
| 交互原则 | **孩子只和机器人对话**；小程序是壳，不答题、不自动回复；所有问答内容 = 机器人预置语料                                                 |
| 难度控制 | **CEFR A2**、句子 ≤ 15 词、少用被动语态、生词即学即释                                                            |
| 术语规范 | 术语首次出现必须**中英对照**（nuclear power plant 核电站、reactor 反应堆、radiation 辐射、uranium 铀、cooling tower 冷却塔） |
| 内容红线 | **不涉核武器 / 核事故惨状 / 政治敏感**；辐射走正面科普基调                                                             |
| 数据规范 | **不编造数据**；引用数字必须标注「数据截至 XXXX 年，上线前请核对」                                                         |
| 交付格式 | Markdown，主题之间用 `---` 分隔，方便开发**按块解析录入**                                                         |
