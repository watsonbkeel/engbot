学生实际使用步骤

  1. 在设置中填写自己的 HTTPS 模型地址、模型 ID 和 API Key，点击测试并保存。请选支持当前 chat/completions 与 JSON 输出的模型。
  2. 在今日练习选择年级、难度和中文帮助，再打开“自己设计场景”。
  3. 写清地点、双方角色、想完成的事；如果要练主动发问，写“由我来问”。点击 AI 生成并检查五个字段。
  4. 点击“保存并去安排练习”，回到今日页确认选中场景对话，再保存安排；原有其他草稿选项会保留。
  5. 下次开课进入角色。听不懂可请求解释，不会说可请求表达帮助；任务完成并自然接受结果或告别后进入点评。

仅保存场景也可选。完整练习模式先练词再进入所存场景；直接练角色对话用场景模式。当前保存一个正在使用的场景，不是多场景收藏库。
