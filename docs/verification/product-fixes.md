## 真实听力生成与恢复证据

45 篇原稿每篇 151–168 词，每个年级 3 篇短文 + 2 段对话。它们属于分级原创听力素材，未被用作教材词库替换。

首次 Edge 请求因环境 DNS 失败；主流程尝试代理后仍遇 WebSocket 403。因此实际交付明确选择 **Piper TTS 1.3.0 / en_US-ljspeech-medium**，而非伪造 Edge 成功。生成采用真实合成波形并以 ffmpeg 调速/编码，不拼接静音、不循环素材。
