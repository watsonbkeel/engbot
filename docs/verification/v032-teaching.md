# v0.3.2 教学流程复核与修复证据

日期：2026-10-21。基线：`98eaddd3c4a35ab23a5e02ba373f05f0c2d645c9`。

本报告覆盖真实 `Tutor` 状态机、提示词和场景模板。模型响应使用明确放在 `tests/` 内的可控替身，验证状态和模型输入；没有调用学生真实账号，也没有把替身输出当成真实模型教学效果。

## 结论

原系统已有四模式、求助后回原题、逐词证据和场景轮次限制，值得保留。本轮发现的问题集中在“把什么算作成功”以及“模型看得到哪些实际学习证据”。已修复三个可以直接复现的假阳性/上下文缺口，并补充本次词汇观察和更自然的交流要求。原 `word_id`、0/1/2 历史最高状态和三个累计证据字段均保持不变。

## 1. 可复现的问题与现在的行为

| 问题 | 修复前的实际输入与输出 | 修复后 |
|---|---|---|
| 猜词清单也算成功跟读 | `zh2en` 目标 apple，先答 orange 进入跟读，再说 `apple banana orange`；输出“这次跟读说出来了”，`imitated=true`，并结束 | 跟读阶段检查整条规范化转写是否等于刚示范的词形；先再示范一次，第二次仍不符合则继续，成功模仿计数不增加 |
| 错误使用也算成功模仿 | 先示范 `I want an apple`，孩子说 `apple is a car`；模型明确给 `correct=false, independent=false`，原引擎仍写 `imitated=true` | 分开“此前给过词/属于拷贝”与“本次使用正确”；该错误不会增加成功模仿、有效回答或独立用词证据；错误回忆中提到示范词同理 |
| 只解释出意思也被笼统肯定为完成取词 | 模型认为 `a red fruit` 语义可接受，但回答不含 apple；原来直接说“对！” | 反馈改为“意思表达出来了，这个目标词还要练”；仍保留既有合同 `answer_valid=true, used_word=false`，不升到 2 |
| 点评看不到一句流利回答其实刚受过帮助 | `howtosay → 中文意图 → 英文示范 → 跟读 → 回原题` 后，原点评输入仅含 `I would like an apple.`，不含支持信息 | 本轮判断输入带 `answer_support`，历史中的对应学生句带 `support`；点评可以区分帮助后完成与独立表达，后续无帮助回合不会沿用旧标记 |
| 历史最高状态掩盖本次困难 | 历史状态 2 的 apple 本次回忆答错、只能跟读；对话模型以前只收到词表与对话，无法看到这次困难 | 原状态 2 不倒退；传入独立的本节最新观察 `phase=repeat, correct=true, independent=false, imitated=true`，供同一模型调用选择合适的后续练习 |

“跟读整答”只用于明确要求重复词的 `repeat` 子阶段，忽略大小写、标点和多余空格，要求复现刚示范的词形；例如示范 apple 后 `APPLE!` 通过，`apples` 会再听再试；示范本来就是 apples 时，`APPLES!` 通过。不将正确英语复数说成语法错误。普通回忆/场景回答继续按任务和逐词语义判断，原有词形识别不变。该检查只确认识别文本是否完成这项练习，不评价声音、口音或发音质量。

## 2. 教学设计的有限调整

- 所有难度均接受完成交流任务的自然短回答；`standard` 不再被写成强制学生完整句。`basic` 在需要时才给选择，不要求每题都先把答案选项说出来。
- 孩子提出符合情境的问题、请求澄清或合理拒绝，同样是交流；机器人先回应，再继续任务。
- 每次自然复述最多一处有用纠正，肯定必须对应观察到的具体表现；不能为了填满点评而编出三条错误。
- `session_word_observations` 只记录本节每个目标词最近一次实际尝试。未听清和缺失语义证据不制造错误观察。提示词要求：只有符合当前场景时，才给困难词一次新的、未示范的表达机会；不把角色扮演变成逐词翻译清单。
- 新增靠前的“文具店”和“午餐点餐”，各用三个简短交流步骤，允许词/短语回答；原丛林、诺曼底、核电站三个兴趣模板全部保留。

这些是本产品的设计判断。已验证的是约束和证据被正确传入模型，不是宣称模型在真实儿童语音上始终理解正确，也不是已经证明学习效果提高。

## 3. 数据、恢复与边界

新增信息只在引擎内部和现有 LLM 用户 JSON 中使用，不新增公共 API 字段、数据库评分或额外模型调用。

`answer_support` / 历史 `support` 只含是否求助与原始目标词 ID。`lesson_observations` 至多对应本批 10 个词，每词只含原 ID、阶段及布尔事实，不存孩子原话、中文意图或英文帮助全文。原对话历史仍由现有结束清理逻辑管理。

短期回合快照恢复显式为 v0.3.1 快照补 `task_helped`、`lesson_observations` 默认值；不把当前失败回合的整个内存状态混入旧快照。词汇续学断点保留已有观察；真正新课清空上一课观察。历史最高档仍只是曾经达到的状态，不被改写为“当前一定掌握”。

逐词模型证据仍可能判断错误。代码保守校验缺失/畸形证据、真实出现、拷贝和受助状态；没有用假回答替换服务故障。

## 6. 真模型/真机后续验收建议

将以下作为目标环境的人工观察点，不声称本轮已经完成：同一个场景在三个难度下，孩子分别回答一个合适词、一句短语和一句完整句，均不应仅因长短被否定；求助后的回答应被表述为有支持的成功；错误、猜词和不知道应得到适量帮助；已有历史状态 2 的词答错后，不能被点评成“本次已经掌握”；场景结束应保留最后一句纠正，且不再问新题。

继续核对儿童 ASR 转写、真实 LLM 的逐词证据与反馈、实时 TTS 听感、树莓派和微信环境。上述自动化测试不替代这些验收。
