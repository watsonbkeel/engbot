## 学习目标

- “解释当前问题”和“不会表达”分开。中文意图→英文示范→尝试跟读→返回原任务，帮助没有推进原题或直接算独立掌握。
- 逐词判断语义正确和独立性，不再把整句相关等同于每个出现的词都已掌握；没有可靠证据不升级。
- 历史最高状态保留；听辨有效回答会计数；没有说出示范内容的失败尝试不被记录为成功跟读。
- 退出续学保留帮助和示范标志，不能把即时回声重新算成独立答案。
- 场景有角色、目标和开场；两次开场失败后示范进入，避免反复卡住；按难度 6/8/10 轮，支持英文和中文结束。
- 最后一轮角色纠错与回应保留，再给赞许和最多三条建议；模型点评失败仍可结束。
- 学段语速贯穿返回协议和真实 TTS 适配，慢速请求进一步降速。

## 研发可靠性

| 风险 | 处理 |
|---|---|
| 答案提交后响应丢失，旧答案判到下一题 | request_id + session_id + question_id；旧题在 ASR 前拒绝，原请求可重放 |
| 部分词条已写入，下题失败导致重新判断 | 持久化首次判断与稳定写入意图，幂等键和正文不变 |
| Pi 异常时录音队列继续堆积 | 仅保留未确认回合，冻结新答案，用原编号恢复，可明确停止 |
| 首次开课未确认时停止口令无效 | 真实语音入口识别排队／未确认的开课，允许明确停止，避免重复开课 |
| 最后点评播报失败后无法重听 | Pi 内存保留最后回复；空闲 tick 不覆盖；重听只重新合成／播放，不判题、不写进度 |
| 默认运行日志留下完整儿童话语 | 正常日志只记录长度、段数、状态等；完整话术只在显式文字调试终端显示 |
| 下一阶段失败仍提前清词汇断点 | 成功持久化新回合后才提交断点变更 |
| 畸形 LLM 响应冒出内部类型错误 | 归一 ProviderError，按配置回退真实平台服务 |
| DNS 阻塞超时外／冷启动加载多个 Vosk | 异步有限 DNS 工作、统一 deadline；模型冷加载单次执行 |
| 旧桥相同文本永远复用同一结果 | 相同文本的不同投递是不同事件；显式原编号才代表重试 |

短期恢复日志最长 6 小时、最多 128 个完成回复；Pi 为确认当前请求临时保留一次原音频。数据使用私有目录和文件权限，完成或过期清理。结束点评的重听缓存只在 Pi 内存中保留，明确停止、新开课或进程退出时清理。它不提供永久儿童语音档案。

## 真实材料与交付

原 WordMaster_SZ 词库保留 3,919 条和原始 word_id；未发明教材单元。45 条听力为真实 Piper 神经语音生成，采用真实时长调速，没有静音填充或循环凑时长。构建中两条不完整音频被最终摘要门禁拒绝，经正式原子生成器重建后重新逐条解码和验证。

源码包剔除真实家长连接文件、SSH 密码安装辅助文件、个人配置、缓存和虚拟环境。安装／升级文档明确公共模板与学生副本的差别，要求 Pi 和脑端协议配套升级。

## 复核方式

先写能复现旧问题的失败回归，再修改实现；实施代理自审后再做独立代码审查。独立审查继续追查真实入口，尤其是首次开课无响应和最后点评播报失败场景；具体发现、修复和复测见 `verification/final-review.md`。

最终总测试数、完整门禁命令、压缩包和素材校验以 `TEST_REPORT.md` 为准。真实模型教育质量、儿童识别效果、USB 耳麦、微信手机与实际响应时延没有被本地替身测试替代。
