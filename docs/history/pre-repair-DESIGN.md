# 英语听说课程作品：执行规格
用户已确认 V0.2，并直接要求实现完整代码和部署文档。
## 边界
- 现有 Raspberry Pi 4B + USB耳麦，树莓派身体 / Linux脑端结构。
- 直接使用 WordMaster_SZ 开源 fullDictionary.js，不编造教材单元。
- 公共层管理 words/config/progress、模型/语音密钥。学生层独立目录、端口和进程。
- 小程序学生作品两页：配置、结果，提供独立可导入版本和非破坏性合并脚本。
- 一条主线：配置 -> 听词/提取 -> 情境对话 -> 持久化进度。
- status 0/1/2；跟读不得升级到2；没听清不扣分；只记录实际练过的词。
## 已决定的实现细节
词库默认 unit=0 取本学期；非零 unit 为原始顺序每10词的“练习组”，界面明确非教材单元。
每节选词：范围内约2/3复习（练过但未到2，按最久未练优先）+1/3新词（按词典顺序），另有状态2且7天以上未练的词每节抽查1个；不足时依次用新词、抽查词、其余词补齐。
词形变化（复数、过去式、-ing、常见不规则形式）视为说出目标词；词组只变化首词。两个字母以内的词（be/I/it/we）只认原形和不规则表，不按规则加词尾（避免be→bed、I→is）；有不规则过去式的动词不再生成规则-ed（避免see→seed）；单音节重读闭音节只生成双写形式（hop→hopping，不生成hoping）。英文线索的泄露检查同样按变形判断（线索含apples即视为泄露apple）。回忆阶段升级到“会说了”须本人说出目标词（含变形），判题说对但没说出这个词不升级。
进度额外累计三项证据：回答有效、说出目标词、跟读/模仿（紧跟老师明确示范“你可以说/跟我读/for example”等后说出）。三项各自独立累计（跟读时说出目标词，两项都加1），家长页分开显示“说出目标词N次；跟读/模仿M次”，不写成“其中”。跟读阶段未说出目标词时重示范1次，仍未说出则跳过，不升级。
SQLite/WAL单公共进程写入；每生parent和brain凭证分开，Pi另有本生edge凭证。
默认DeepSeek官方兼容HTTP接口，thinking disabled；可覆盖模型名称和URL。
语音支持公共层Vosk和兼容ASR HTTP；TTS支持原项目Edge及兼容HTTP。
Pi课程语音插件采用本地中文唤醒、服务器英语识别和出站HTTP音频，避免依赖云端反向访问家庭Pi。
原aibot文件不自动覆盖；仅显式启用时暂停原nox-voice，可恢复。兼容传统bridge文本输入。
