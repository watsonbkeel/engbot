修改前主要问题是机器人抢提问权、已完成的任务被固定轮数延长。修改后采用角色与主导权保留、实际预算和可选自然结束信号；四案均没有多余告别轮次。这里的轮数不包含开场示范和帮助分支。故事中的付款、认领、送水是模拟交流，不代表现实动作或真实口语等级。

修改前42次、修改后29次实际模型输入输出已保存；各案例完整脑端响应可核对。GPT也扮演学生，前后重新生成了话语与细节，不能把轮数对照解释为受控学习效果实验。所有开场白均跟随示范，不能算独立产出。

手工文件桥将生成等待时限从20秒临时延长为600秒，正式服务仍为20秒；不以此测量实际延迟。最后新增的relevant=true矛盾保护在改进模拟进程启动后加入，四个实际提前结束回复均为relevant=true，故该保护不会改变这四个结果；矛盾输入另由失败复现和独立回归验证。
