## 2. 英语教学复核

| 教学判断 | 当前验证内容 |
|---|---|
| 成功跟读 | 整答匹配刚示范原词／原短语，容忍大小写、标点、空格；猜词列表、无关提及、推导伪词不算成功；失败可重试后继续，不虚增次数 |
| 示范后错误回答 | “复制／受过示范”与“正确模仿”分离；模型判错不增加成功模仿 |
| 释义与取词 | 意思表达正确但没说出目标词时，反馈说明还需练习；有效回答计数与实际使用目标词分开 |
| 求助后的表现 | 当前判断与对应历史句携带求助／示范标记，下一独立回合清除旧标记；无目标词场景也保留求助事实 |
| 本轮困难 | 对话与点评接收本批最多 10 个词最新事实，历史最高档不冒充本轮掌握；未听清不制造负面观察 |
| 恢复与新开课 | 老快照显式补默认值，失败回滚不保留新临时字段；续学保留观察，新开课清除旧观察 |
| 对话设计 | 自然短回答、回应孩子问题、具体且克制的反馈；“文具店”“午餐点餐”靠前，原三个模板保留 |
| 家长记录 | 历史达成／累计次数清楚；无词汇记录不等于没练对话，ASR 不是发音评分 |
