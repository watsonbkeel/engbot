## 2. 学习目标

- `full`、`en2zh`、`zh2en`、`scene` 四种模式，均使用交付的真实 3,919 条词库，通过实际回环 HTTP 走到结束并读取 SQLite 学习结果。模型回复由明确标记的测试替身提供，以便重复验证状态机。
- “这是什么意思”和“我不会说”分别走解释与表达帮助；中文意图、英文示范、尝试跟读、返回原任务形成闭环。求助不跳题，辅助输出不直接算独立掌握；关闭中文辅助时用英文。
- 同一句的多个目标词逐词核证；畸形、缺失或不可信证据不升级。历史最高状态保留，成功跟读与独立表达分开。
- 场景开场可失败后示范进入；按难度完成 6／8／10 轮；最终回复保留最后纠错与收尾点评，点评模型失败也能结束。
- 停止、恢复和新的开课不会把旧题、旧音频或帮助后的即时回声算到下一道题。

证据：`learner-fixes.md`、`real-dictionary-workflows.txt` 与完整测试输出。学习状态正确不代表真实模型在每次儿童回答上都判断准确。

## 3. 研发可靠性与独立复核

独立审查员没有编写实现，重新读代码并运行边界复现。最终状态以 `verification/final-review.md` 为准。复核重点包括：

- request_id／session_id／question_id 一致性；旧题音频在 ASR 前返回 409。
- 多词部分写入后响应丢失、脑端进程重建、重发原请求：首次判断被重用，各词有效与使用计数均不重复。
- 首次开课尚未确认时，从真实语音 route 入口仍可明确停止。
- 最后纠错／点评的 TTS 或播放失败后可重听，不再次判题或写学习进度；普通空闲 tick 不能覆盖待重听回复。
- 默认运行日志不写儿童识别全文和机器人回复全文；显式 `--text` 调试仍可查看话术。
- 同时保存或切换课堂时，旧响应不丢新草稿、不让模型表单永久锁住。
- 家长、脑端、Pi 角色隔离；私有恢复文件、限时限量缓存；模型异常回退、DNS 总超时、Vosk 单次冷加载。

短期恢复例外：脑端回合恢复记录最长 6 小时、最多 128 个完成回复；Pi 未确认请求有私有临时录音。词汇续学断点保留 7 天。它们不提供永久会话或原音频档案。

## 5. 尚需目标环境验收

以下不在本地验证证据范围内，部署时按 `INSTALL.md` 第 8 节逐项完成：

1. 真实模型账号、模型 ID、JSON 输出稳定性、真实教育反馈是否恰当。
2. 真实中文／英文 ASR，儿童口音、噪声和语速；ASR 结果不是发音评分。
3. 实时 TTS 的网络可达性、中文／英文朗读及听感。预生成 MP3 可用不等于实时 TTS 服务可用。
4. 树莓派 USB 耳麦、ALSA、扬声器回声与实际唤醒；停止／重听口令在物理设备上的表现。
5. 微信开发者工具与手机的实际渲染、AppID、request／downloadFile 合法域名和权限。
6. 真实端到端延迟、并发和长时间运行。
