## 已实现的主流程

家长连接课堂 → 设置年级、词汇范围、练习模式和场景 → 孩子在树莓派发起练习 → 听辨／主动说词／情境交流 → 遇到困难时解释或表达帮助 → 回到当前任务 → 结束点评 → 小程序查看学习记录。

| 模式 | 本轮任务 |
|---|---|
| `full` 综合练习 | 听懂词义 → 主动说词 → 简短对话 |
| `en2zh` 听辨 | 听英语、回答词义，完成后收尾 |
| `zh2en` 主动说词 | 根据提示独立说英语，完成后收尾 |
| `scene` 场景 | 用配置的开场白进入角色，按目标进行最多 6／8／10 轮对话；目标完成并自然告别可提前点评 |

“这是什么意思”和“我不会说”有不同处理。需要表达帮助时，孩子可以先说中文意图，获得英文示范、尝试跟读，再回原题；辅助后的输出不会直接当成独立掌握证据。`chinese_help=false` 时使用英文帮助。

## 学生自己设计场景

1. 在设置页填写自己的公网 HTTPS 模型地址、模型 ID 和 API Key，点击测试并保存。真实配置通过实际 JSON 请求验证后才保存。
2. 今日练习先选年级和难度，再进入“自己设计场景”；描述地点、双方角色和想完成的事情，也可明确“由我来提问”。
3. 点击 AI 生成，检查并编辑场景名、机器人角色、学生角色、目标和英文开场白。
4. 点击“保存并去安排练习”，今日页会选中“场景对话”，同时保留未保存的其他安排；再点击保存今日安排，下次开课使用它。
5. 机器人先带入开场白，再根据实际回答逐轮生成角色对话；目标完成并自然收尾后给出简短反馈。需要帮助时可解释当前话语或用中文说明想表达的意思。

“仅保存场景”保留为另一个入口。完整练习模式会先练词汇，再使用已保存的场景；直接练场景请用场景对话模式。目前配置保存一个当前场景，AI 生成草稿不会自动覆盖它。

## 本次修复重点

- 自带模型 Key 加密保存，主密钥独立文件0600；旧库分阶段迁移。**升级前先备份，迁移后不能只回退旧代码。**
- 自带模型失败默认不回退平台；设置页明确开启才允许，并展示最近状态与实际使用的模型。
- 场景页显示请求／成功／剩余次数，失败包含在20次尝试上限内；编辑期间的旧响应不会覆盖新草稿，也不会漏掉次数刷新。
- 公共请求提供安全错误码与反馈编号；错误校验不回显Key；音频格式、上传和识别等待、并发工作均有边界。
- 脑端复用HTTP连接；前端共用可暂停、有退避的轮询；听力工具用稳定错误码，并修复符号链接临时目录造成的跨环境测试失败。

## 保留的 v0.3.3 场景教学改进

- 场景保存后有明确的安排入口，保留今日草稿，并防止跨课堂或迟到请求串用。场景页显示年级，可直接前往自己的 API 设置，复制提示词也带实际年级。
- 保留学生指定的双方角色与提问权。学生当店员、采访者或导游时，机器人可以自然回答，不再强制每句话都反问。
- 模型收到真实的剩余轮数，生成的核心任务按六轮内可完成来设计，避免临近上限才突然收尾。
- 增加可选的严格布尔值 `scene_complete`：至少发生两轮学生交流，实际完成核心任务并自然收尾时允许结束；旧模型不返回该字段仍兼容原轮数上限。结束本身不增加词汇掌握证据。
- 自带 API 在关闭深度推理时，如果服务商明确拒绝整个 `thinking` 参数，才移除这一字段并在原时限内重试一次。支持该参数的服务保持原请求；开启状态不会被偷偷改成关闭，其他参数错误也不会被掩盖。
- 前版四组 GPT 实际对话及修改前后记录随包保留；它们是历史模拟证据，不代表本次又调用了四组真实供应商或已验收儿童体验。

v0.3.3 的问题与修改见 [CHANGELOG_V033.md](docs/CHANGELOG_V033.md)，完整对话可用浏览器打开 [SCENE_SIMULATION_REPORT.html](docs/SCENE_SIMULATION_REPORT.html)。v0.3.2 的录音恢复、模型连接安全、学习证据与前端可靠性改进全部保留，历史改动见 [CHANGELOG_V032.md](docs/CHANGELOG_V032.md)。

## 文件内容

| 路径 | 用途 |
|---|---|
| `english_class/` | 公共服务、学生脑端、课程引擎、数据库、模型与语音适配 |
| `pi/` | 树莓派录音、唤醒／控制、播放及失败恢复 |
| `miniprogram/` | onboarding、today、scenes、settings、listening、english-result 六页源码 |
| `data/` | 原始词库、来源摘要、听力文稿和音频索引 |
| `scripts/`、`deploy/` | 构建、安装、模型准备和服务配置 |
| `tests/`、`tests_js/` | 后端、音频协议与实际六页前端的回归测试 |
| `docs/verification/` | 修复记录和本次复核证据 |

原 WordMaster_SZ 词库已从用户提供的项目中导入：**3,919 条，覆盖 1—12 年级、24 个学期**；原文件摘要与锁定版本一致。没有另造教材词库。`unit=0` 是全学期，正整数是原词表顺序每 10 个词的练习组，**不代表教材单元**。

源码包不含真实密钥、学生凭证、个人连接文件或 Vosk 权重。真实 LLM、ASR/TTS、树莓派耳麦、微信手机端及端到端延迟仍须在目标环境验收；自动化测试中的替身只在测试目录，运行时不会用它们回答学生。

## 自行复核

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
bash scripts/test_all.sh
```

需要 Python 3.11+、Node.js 和 ffmpeg/ffprobe。脚本按显式 PYTHON → 项目 .venv → python3 选择解释器，并先检查依赖、记录版本。本次实际环境为 Linux/Python 3.12.14/Node 24.19.0/ffmpeg 6.1.1；Mac CI 配置已提供但未在本次运行。真实供应商测试不包含在默认命令里，也不需要真实密钥。
